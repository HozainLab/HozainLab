# HozainLab

**Код, дизайн интерфейсов и автоматизация с ИИ**

Учусь заочно в магистратуре по прикладной информатике. Около двух лет работал в чат-поддержке. В личных проектах формулирую требования, собираю интерфейсы с помощью Codex и проверяю пользовательские сценарии. Ищу первую удалённую работу или оплачиваемую стажировку в разработке.
